Express HTTP server that wires Battlesnake handler functions to the engine's API endpoints.

(require("server"))(handlers) → {void}

Creates and starts an Express server that implements the Battlesnake HTTP API. Registered routes: - `GET /` → BattlesnakeHandlers.info (snake metadata) - `POST /start` → BattlesnakeHandlers.start (game start hook) - `POST /move` → BattlesnakeHandlers.move (per-turn move decision) - `POST /end` → BattlesnakeHandlers.end (game end hook) The server listens on `0.0.0.0` and the port defined by the `PORT` environment variable, defaulting to `8000`.
Parameters:
Name Type Description
handlers BattlesnakeHandlers Object containing the four required handler functions.
